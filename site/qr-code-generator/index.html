    How to make a QR code

    1. Choose what the code should open: a link, a Wi-Fi network, a WhatsApp chat, an email, a phone call, a UPI payment or plain text.
    2. Fill in the details. The preview updates as you type.
    3. Pick a colour and size, then tap Download PNG for phones, documents and social posts, or Download SVG for printing and design software (it stays sharp at any size).
    4. Scan the downloaded code with your own phone before you print it.

    The code is drawn by this page on your device. Nothing you type is sent to a server, there is no account, and the code never expires because it contains the information itself rather than a redirect link.

    Worked example: a Wi-Fi QR code

    Network Sharma Home, WPA2, password mango;tree42. The semicolon is a separator in the Wi-Fi format, so it is written as \;, and the code holds WIFI:T:WPA;S:Sharma Home;P:mango\;tree42;;, which is 42 bytes. At level M that fits in a version 3 code of 29 × 29 squares; at level H it needs version 5, 37 × 37 squares. Guests point their camera at it and tap Join. Backslashes, semicolons, commas, colons and double quotes are escaped automatically.

    Error correction: which level?

    LevelDamage it can surviveBest for
    Labout 7%Long text on screens
    Mabout 15%Most uses (default)
    Qabout 25%Printed signs and stickers
    Habout 30%Codes that may get scratched or dirty

    Higher levels make the pattern denser, so they need a larger print to scan from the same distance. The largest QR code holds 2,953 bytes at level L and 1,273 at level H; this page tells you when your content is too long.

    Tips for codes that scan first time

    • Keep a dark code on a light background with strong contrast. Light-on-dark codes fail on many scanners.
    • Leave the white border (quiet zone). The download includes the standard four-square margin; do not crop it.
    • For long text, put it on a web page and make a QR code for the link instead.
    • For UPI, check the name your UPI app shows before paying. Shops that need payment records should use the QR code issued by their bank or UPI app.

    Frequently asked questions

    How do I make a QR code for my Wi-Fi?

    Choose Wi-Fi network, type the network name and password exactly, pick the security type (WPA for most home routers) and download the code. Phones that scan it offer to join the network.

    Do these QR codes expire?

    No. The link, text or Wi-Fi details are stored inside the code itself, so it keeps working for as long as the information in it is correct. There is no redirect service that can be switched off.

    Should I download PNG or SVG?

    PNG is an image for phones, documents, WhatsApp and social posts. SVG is a vector file that stays sharp at any size, so it is better for printing posters, menus and stickers.

    Is my Wi-Fi password or data uploaded?

    No. The code is created in your browser and nothing you type is sent anywhere. The Wi-Fi password is not saved by the page either.
