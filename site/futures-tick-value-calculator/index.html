    Tick size and tick value

    The tick size is the smallest price step a contract can move, and the tick value is what one tick is worth per contract. P&L = (exit − entry) ÷ tick size × tick value × contracts.

    Frequently asked questions

    What is the tick value of ES?

    The E-mini S&P 500 moves in 0.25-point ticks worth $12.50, which is $50 per full point.

    What is the tick value of NQ?

    The E-mini Nasdaq-100 moves in 0.25-point ticks worth $5.00, which is $20 per point.

    What is the tick value of crude oil futures (CL)?

    CL moves in $0.01 ticks worth $10 per contract, which is $1,000 per $1 move.

    What is the tick value of gold futures (GC)?

    GC moves in $0.10 ticks worth $10 per contract.
